# Classmix

クラスの生徒を、男女の人数バランスを考慮してグループ分けするブラウザーツールです。濃紺とライムのシンプルな画面で、班ごとのメンバーをまとめて表示します。

## 機能

- 出席番号または名前で生徒を登録
- 初期設定は46人、女子1〜18番（変更可能）
- 女子の出席番号を範囲または個別に指定し、残りを男子として自動設定
- 班の数、または1班の人数を指定
- 女子・男子それぞれの人数を班間で最大1人差に調整
- 欠席者の除外、シャッフルアニメーション、再シャッフル
- 結果のコピー・印刷・表示モード
- 設定をブラウザーのlocalStorageに保存

## 使い方

1. 生徒数、分け方、女子の出席番号を指定します。
2. 男女のバランスを調整したい場合は「男女を均等に」をオンにします。
3. 「班をつくる」を押します。

クラス名・欠席番号・性別の個別指定は「詳細設定」から変更できます。名前で登録すると、入力順が出席番号になります。人数指定の場合、班の人数が指定値を超えないように班数を決めてから、人数をできるだけ均等に分けます。

## ローカルで開く

ビルドや依存パッケージのインストールは不要です。`index.html` をブラウザーで開いて利用できます。

HTTPサーバーを使う場合、Pythonが入っている環境では次のコマンドで起動できます。

```sh
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。コピー機能は、ブラウザーの権限や実行環境により利用できない場合があります。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面・フォーム |
| `app.js` | 登録・人数配分・保存・アニメーション |
| `style.css` | レイアウト・班カード |
| `updates.css` | 入力部品・アニメーション |
| `theme.css` | 濃紺とライムの配色 |

## データの扱い

名簿や設定は利用するブラウザー内に保存され、アプリからサーバーへ送信しません。このリポジトリに実際の生徒の名簿は含まれていません。フォントの取得にはGoogle Fontsへの接続が発生します。保存先はURLのオリジンごとに異なります。
